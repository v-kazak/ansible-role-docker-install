# Роль для подготовки Docker-хоста

Ansible playbook и роль для установки Docker на Debian и Ubuntu.
Эта роль подойдет вам, если у вас есть только логины и пароли от удалённых машин, а SSH ключи ещё не добавлены.

Сейчас роль делает следующее:

- устанавливает Docker Engine из официального репозитория Docker
- создает группы `deploy` и `docker`
- создает пользователя `deploy` и добавляет его в группу `docker`
- добавляет локальный ключ из вашего каталога `~/.ssh/id_ed25519.pub` в `authorized_keys` пользователя `deploy` на удалённое машине
- отключает вход по SSH по паролю
- включает и запускает сервис Docker
- выводит устнановленную версию Docker

## Поддерживаемые платформы (протестировано)

- Debian
- Ubuntu

## Требования

- установленный Ansible
- локальный публичный ключ `~/.ssh/id_ed25519.pub`

## Использование

1. Задайте список хостов, логины, пароли в файле `inventory.ini`.
2. Запустите playbook: `ansible-playbook playbook.yml`

ВНИМАНИЕ! Хранить пароли в inventory.ini это дыра в безопасности! Удалите их после первого запуска!

## Примечания

- Роль поддерживает только Debian и Ubuntu и завершится с ошибкой на других дистрибутивах.
- Docker ставится из официального репозитория `download.docker.com`.
